Salta Dúo

Plataformas cooperativo. Juega solo o con un amigo, los dos a la vez.

¿Cómo se juega?
  • ◀ ▶ moverse · A saltar (mantén para saltar más) · B correr.
  • Salta encima de los enemigos para vencerlos. Los de pinchos no se pueden pisar.
  • Recoge monedas y las 3 estrellas de cada nivel. Los muelles te lanzan muy alto.
  • Con un amigo: saltad uno sobre la cabeza del otro para llegar más alto. Las puertas se abren mientras alguien pisa su botón.
  • Si te caes, vuelves a la última bandera. El nivel acaba cuando todos llegan a la meta.
  • Teclado: flechas, Z o espacio para saltar, X para correr.
